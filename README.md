# 🏡 Real Estate Search App

A modern real estate filtering and search application built using
**HTML, CSS, and JavaScript**.

------------------------------------------------------------------------

## 🚀 Features

### 🔍 Search System

-   Live search (updates while typing)
-   Debounced search for better performance
-   Keyword matching using smart word splitting
-   Highlight matched keywords in results

------------------------------------------------------------------------

### 🧠 Filtering

-   Filter by:
    -   Property Type
    -   Location
    -   Status (For Rent / For Sale)
-   Combined filtering logic (all conditions applied together)

------------------------------------------------------------------------

### 📊 Results Handling

-   Dynamic results count
-   Unique counting using `Set`
-   Automatic tab switching to matched results

------------------------------------------------------------------------

### 📬 Contact Form (Advanced UX)

-   Real-time validation
-   Custom error messages per input
-   SweetAlert integration (success & error)
-   Loading animation before success
-   Clean reset after submission

------------------------------------------------------------------------

### 🎨 UI Enhancements

-   Smooth card animations
-   Highlighted search matches
-   No Results message with styling
-   Loading spinner (simulated loader)

------------------------------------------------------------------------

### 🔄 Reset System

-   Reset button clears:
    -   Inputs
    -   Errors
    -   Results
    -   Active tabs

------------------------------------------------------------------------

## ⚙️ Technologies Used

-   HTML5
-   CSS3
-   Vanilla JavaScript
